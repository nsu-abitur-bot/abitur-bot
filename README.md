# abitur

## Описание проекта

Проект — это телеграм-чатбот для абитуриентов НГУ. Он служит для консультации абитуриентов по вопросам поступления и обучения в университете. Чатбот помогает решать следующие задачи:

- Предоставление ответов на вопросы о поступлении и обучении в НГУ.
- Уведомление пользователей об изменении их места в рейтинговых списках поступающих.

### Основные функции

1. Ответы на вопросы абитуриентов о поступлении и обучении в НГУ с использованием подхода Retrieval-Augmented Generation (RAG).
2. Уведомления о перемещении пользователя в рейтинговом списке.

### Задачи и Цели

Процесс поступления в университет является сложным и в некоторых случаях стрессовым. Бот решает эту проблему, упрощая доступ к информации и автоматизируя процесс мониторинга рейтинговых списков. Кроме того, цель проекта — повысить привлекательность и удобство поступления в НГУ.

### Ожидаемые результаты

Создание инструмента, который снизит уровень тревожности у абитуриентов, предоставит доступ к полной и структурированной информации, а также укрепит имидж НГУ как современного учебного заведения.
