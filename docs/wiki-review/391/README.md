# Редакция Wiki для ревью, #391

В `pages/` находятся все 12 страниц Wiki. Исходная версия и проверенные версии
приложений записаны в `baseline.json`. Первый коммит сохраняет исходные страницы,
следующий содержит редактуру. Их сравнение показывает правки текста.

Публикация в действующую Wiki выполняется отдельно после ревью. Эта папка
предназначена для проверки предложенной редакции, действующей остаётся Wiki.
Код приложения, эталоны и исходные результаты измерений здесь не меняются.

Основания: принятый отчёт #390 / PR #469, результаты #388 и отдельная задача
#470 на оставшиеся живые проверки. Общая заморозка остаётся решением #387.

## Как смотреть изменения

- Коммит `fb55ddb` содержит исходные страницы Wiki.
- Сравнение этого коммита с текущей веткой показывает только редактуру.
- Наиболее заметные изменения находятся в плане релиза, SRS, SAD и лимитах моделей.
- Список проверок и ограничения находятся в `verification.md`.
- SHA исходных страниц записаны в `baseline.json`, готовых - в `edition.json`.

## Публикация после ревью

Сначала сверить текущий master отдельного Wiki-репозитория с `wiki_base`
из манифеста. Если появились правки коллег, перенести их и повторить проверку.
Затем перенести ровно 12 файлов из `pages/`, проверить diff и создать
подписанный коммит Wiki. Публиковать его только после ревью и поручения
на обновление Wiki. Схемы, команды и ссылки остаются в формате Wiki.

## Что нужно проверить Марату

Соответствие редакции принятым критериям #390, распределение ответственности,
описание Scrumban, сохранность требований и понятность текста. Решение
о заморозке #387, назначение исполнителя #470 и публичная готовность
релиза этим PR не утверждаются.
