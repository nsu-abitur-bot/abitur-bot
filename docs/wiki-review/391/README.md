# Редакция Wiki для ревью, #391

В `pages/` находятся все 12 страниц Wiki. Исходная версия и проверенные версии
приложений записаны в `baseline.json`. Первый коммит сохраняет исходные страницы,
следующий содержит редактуру. Их сравнение показывает правки текста.

Публикация в действующую Wiki выполняется отдельно после ревью. Эта папка
предназначена для проверки предложенной редакции, действующей остаётся Wiki.
Код приложения, эталоны и исходные результаты измерений здесь не меняются.

Основания: принятый отчёт #390 / PR #469, результаты #388 и отдельная задача
#470 на оставшиеся живые проверки. Общая заморозка остаётся решением #387.
