# Вызовы моделей: настройки и расход

Профиль управляет одним обращением к модели. NFR-4 требует учитывать расход всего вопроса:
поиск, CRAG, генерации, инструменты, эмбеддинги и повторы. Эти величины
учитываются отдельно.

## Профили в коде

Значения по умолчанию сверены по `llm/profiles.py` на backend `9acb2c7`:

| Профиль | Назначение | `max_tokens` | `timeout`, с | `temperature` |
|---|---|---:|---:|---:|
| `CHAT` | Ответ пользователю | 1500 | 45 | 0.2 |
| `GRAPH` | Извлечение сущностей и связей | 8192 | 180 | 0.1 |
| `PARSER` | Обработка текста страницы | 4000 | 90 | 0.1 |
| `VISION` | PDF и изображения | 8192 | 240 | 0.1 |
| `INTENT` | Классификация запроса | 50 | 15 | 0.0 |
| `TITLE` | Короткое название | 100 | 20 | 0.2 |
| `EMBEDDING` | Векторы | Не применяется | 60 | Не применяется |

`ConfiguredProfile` читает настройки через `get_setting` из `config/instance.py`.
Параметры: `PROFILE_<ИМЯ>_MAX_TOKENS`, `PROFILE_<ИМЯ>_TIMEOUT`,
`PROFILE_<ИМЯ>_TEMPERATURE`. Для эмбеддингов есть `PROFILE_EMBEDDING_TIMEOUT`.
Фактические значения и поддержку параметров выбранным провайдером фиксируют
в отчёте конкретного стенда.

## Время ответа и общий бюджет

NFR-2: полный ответ с доставкой должен занимать не больше 30 секунд для 95%
запросов. Учитываются очередь, поиск и повторы, время судьи исключается.
Ожидание `CHAT` по умолчанию составляет 45 секунд. Общий срок обработки
нужно обеспечить в коде и проверить во всех каналах.

Для следующего небольшого пилота согласованы пределы на вопрос: 40 генераций DeepSeek, суммарно 32000 входных и 1024 выходных токенов, 512 токенов эмбеддингов.
До запуска нужны контроль этих пределов и денежный бюджет по действующим тарифам.
Постоянный бюджет релиза пока не установлен.

Каждое обращение или повтор к провайдеру считается один раз. Попадание в кэш
без обращения не расходует вызов. SQL-запрос инструмента не является вызовом
модели, а продолжение генерации после результата инструмента является.
FAQ может использовать эмбеддинг, хотя генерация ответа пропускается.

## Что измерено

[отчёт #390](https://github.com/nsu-abitur-bot/abitur-bot/blob/9acb2c7fa4bd83f03660f0d054285a5cb37621b7/docs/reports/390-measurements-2026-11-12.md) пересчитывает сохранённые артефакты #388. Это исторический
прогон приложения с профилем custom и пустыми справочниками, выполненный
10 ноября. Он не измеряет текущее качество настроенного демостенда НГУ.

| Показатель | Ответы с базой, 50 вопросов |
|---|---:|
| Генерации DeepSeek | 1003 |
| Среднее / максимум генераций на вопрос | 20,06 / 31 |
| Входные / выходные токены DeepSeek | 733545 / 23137 |
| Токены эмбеддингов GigaChat | 8524 |
| Оценка DeepSeek по историческим ставкам | 0,56989846 CNY |

Во всём сравнении вместе с пустым контролем, судьёй и калибровкой учтены
992153 входных и 45549 выходных токенов DeepSeek, 18131 токен эмбеддингов.
Расчётная стоимость DeepSeek - 0,74856644 CNY. Стоимость GigaChat и фактические
списания не проверены. Действующий тариф из этих чисел не следует.

Индексация девяти источников учитывается отдельно: 1203833 входных и 284532
выходных токенов DeepSeek, 394398 токенов эмбеддингов. Расчёт DeepSeek -
1,3444631 CNY по историческим ставкам. Два прерывания могли оставить
неучтённые завершения запросов, поэтому это не полный счёт провайдера.
