# Развертывание системы

Следуйте инструкциям ниже, чтобы развернуть систему.

1. Скопируйте файл `.env.example` в `.env`:

```shell
cp .env.example .env
```

2. Откройте файл `.env` и заполните все необходимые переменные окружения.

3. Запустите контейнер:

```shell
docker-compose up -d
```

4. Если необходимо остановить контейнеры, выполните команду:

```shell
docker-compose down
```

5. Для перезапуска контейнеров выполните две команды:

```shell
docker-compose down
docker-compose up -d
```
