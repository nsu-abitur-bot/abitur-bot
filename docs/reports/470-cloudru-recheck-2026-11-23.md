# Повторная проверка Cloud.ru для #470

23 ноября повторён один embedding-запрос, на котором остановилась подготовка
FAQ 21 ноября. Запрос выполнен успешно. Сам FAQ-вопрос и остальные сценарии
пилота в этом запуске не выполнялись.

## Что изменилось у оператора

В `MIHAIL-SELF-SERVICE.md` от22ноября описаны самостоятельные open/resume/close,
отсутствие90минутного окна и консервативное принятие неопределённого резерва.
Перед проверкой штатная команда budget показала58попыток, halted=false и пустой
pending_or_uncertain. Попытка58 сохранена с94токенами/0,003029₽. Это учёт полного
резерва, а не доказательство фактического списания у провайдера.

Технические пределы серии в инструкции увеличены до1000₽ Cloud.ru и100CNY
DeepSeek. Пользователь подтвердил для малого пилота1₽/10000embedding-токенов
и3CNY. Повторная проверка обеспечила эти прежние пределы дополнительным строгим
ограничением перед запросом. Старый Store не копировался поверх операторских
изменений, бюджет не пересоздавался и не редактировался.

## Как выполнен повтор

- Только PG15 target, существующий согласованный run и общий бюджет.
- Штатный root-owned bootstrap `run pilot`, без второго ledger.capture.
- Те же две FAQ-фразы из утверждённого плана, с проверкой их хешей.
- Штатный FAQ embedding provider из текущих настроек, модель
  `ai-sage/Giga-Embeddings-instruct-3B`.
- Публичный локальный tokenizer по текущей политике предсказал94токена.
- Дополнительный guard разрешал только один точный HTTPS POST
  `/v1/embeddings` Cloud.ru. Другие запросы, в том числе DeepSeek и SDK-повтор,
  отклонялись до отправки. Исходный meter оставался в цепочке.
- Ни вопросов на генерацию, ни сообщений Telegram, ни записей в индекс или FAQ.

Согласованный тариф32,22₽/1M также указан в
[официальном обзоре Cloud.ru](https://cloud.ru/blog/embeddingi)
для ноября2026. Исполнитель отказывался от запроса при другом тарифе в политике.
