# Числовые результаты #390

`manifest.json` содержит SHA-256 остальных JSON и основу кода. Данные созданы
03.11.2026 из локальных синтетических проверок.

- `offline-c1.json`, `offline-c4.json` - по 160 прогонов настоящего кода с
  подменёнными провайдерами, поиском и хранилищами. Сохранены только технические
  case ID, исходы и числа. Вопросы и ответы не экспортируются.
- `restore.json` - восстановление новой фикстуры SQL/LightRAG. Только размеры,
  время, результаты проверок и хеши файлов. Сам дамп и база знаний не публикуются.
- `functional.json` - один переход HTTP/API/SQL/cache/BotCore, два синтетических
  пользователя каналов, два вопроса и два отзыва. Нет реальных ID или текстов.
- `local-tests.json` - итог отдельного запуска 57 целевых тестов и время.

Эти материалы не измеряют production-задержки, аудиторию, доступность каналов,
токены или стоимость внешних моделей. Методика и ограничения находятся в
[отчёте](../390-release-measurements.md).
