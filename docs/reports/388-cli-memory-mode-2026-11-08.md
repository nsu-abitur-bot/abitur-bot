# Режим без API и подготовка замера памяти #388

08.11.2026. По поручению пользователя подготовлен режим CLI без сервера API.
Изменения находятся в PR #432. Развёртывание требует установки root-owned
расширения администратором, текущие права позволяют только старые команды.
Реальное потребление памяти приложения и графа этим изменением ещё не измерено.

Состав:

- [исполнитель CLI](../../deploy/evals/388/cli_mode.py) поднимает только тестовые
  PostgreSQL/Redis и одноразовый Python-контейнер
- [overlay](../../deploy/evals/388/cli-overlay.json) отключает API-healthcheck,
  перезапуск и запись в корневую файловую систему
- [генератор расширения wrapper](../../tools/prepare_admission_cli_wrapper.py)
  проверяет точный SHA старого скрипта, остальные команды остаются без изменений
- [программа замера](../../tools/admission_memory_probe.py) загружает настройки
  из БД и открывает копию графа без запросов к провайдерам

Исходные девять документов не переиндексируются. Результат замера должен
содержать пики RAM/RSS, swap, OOM и доступную RAM хоста по этапам. Отказ или
обрыв сохраняется как неуспех. Успешная загрузка графа не докажет, что в лимиты
поместится весь ответ на вопрос.

Порог доступной RAM оставлен 1100 МиБ. В начале подготовки на сервере было
около 823 МиБ. Проверка прав подтвердила единственную разрешённую sudo-команду:
`/usr/local/sbin/abitur-eval388`. Её исходный SHA не изменился.
Ни установка новых root-файлов, ни снижение порога через эти полномочия
не предоставлены. Попыток обхода или фиктивных write-проверок не выполнялось.

[Пакет установки и порядок запуска](../../deploy/evals/388/README.md).
После установки и достаточного запаса памяти можно выполнять замер без
вопросов. Полный прогон и судья остаются отложенными.

Локально прошли 54 теста нового режима и счётчиков usage, Ruff и целевой
Pyrefly для Linux. Проверены отказ по ресурсам и чужим контейнерам, timeout,
прерывание, cleanup, ограничения конфигурации и независимость копии графа.
Синтаксис wrapper с новым dispatch проверен по реально прочитанному исходнику
с указанным SHA. Эти проверки не являются серверным замером.
