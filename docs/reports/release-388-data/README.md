# Проверка изолированных вариантов #388

07.11.2026. Отчёты получены собственным read-only инструментом внутри
двух тестовых контейнеров. В них только разрешённые несекретные настройки,
количества строк, идентификаторы хранилищ и лимиты cgroup.

- `runtime-with-kb.json`: вариант, предназначенный для загрузки документов.
- `runtime-empty-kb.json`: пустой контрольный вариант.
- `preflight.json`: список моделей DeepSeek и HEAD-проверки девяти источников.

В момент проверки оба варианта пустые. Общих хранилищ документов между ними
нет, общий только том блокировки запросов GigaChat. Значения ключей, пароли,
сессии, истории пользователей, полные env и runtime-логи не выгружались.

Эти отчёты подтверждают устройство окружения. Они не измеряют качество
ответов, стоимость индексации, квоты или производительность моделей.
