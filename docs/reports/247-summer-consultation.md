# Реальные вопросы летних консультаций НГУ

Refs #247. Разбор от 06.11.2026.

## Происхождение

Марат записывал вопросы абитуриентов во время летней консультационной работы,
дополнил список по памяти и передал 03.09.2026. Список повторно предоставлен
06.11.2026; дата первого сообщения сверена в локальном архиве Claude Code.
В нём 13 вопросов: бакалавриат — 8, магистратура — 3, аспирантура — 2.
Это не полная выгрузка диалогов и не 40 разных обращений. Персональное имя
сотрудника заменено ролью; личная переписка и локальные пути не публикуются.

## Результат

Все 13 вопросов сохранены с устойчивыми ID и решением по каждому.
Для трёх подготовлен исполняемый поднабор с проверенными по опубликованным
страницам фактами и контекстом, который передаётся боту через `history`.
Контекст этих подкейсов сформулирован агентом, а не восстановлен из летнего
диалога: выбор двух программ, дистанционный договор, документ для заселения.
Он явно сохранён в реестре с отметкой происхождения и передаётся боту.
Особенно вопрос о военкомате имеет другие трактовки; сценарий проверяет только
названную ситуацию, не все возможные ответы на исходную короткую реплику.
У одного из них (дистанционный договор) проверен маршрут начала оформления,
а не полный регламент подписания: эталон не придумывает дальнейшие действия.
Другие 10 остаются пробелами; у них нет фиктивного эталона «уточните».
Они исключены из оценки качества, по каждому записаны нужные сведения и роль
сотрудника, который может их подтвердить. Они связаны с процедурным наполнением
#260; это не утверждение, что ответы уже получены или #247 полностью выполнена.

Агентская проверка источника отмечена отдельно от внутреннего подтверждения
командой и экспертной проверки: обеих пока 0/13. Обзорные страницы других
факультетов и старые правила не переносятся на нынешнее поступление ФИТ.

Адрес воинского учёта не заменяет название нужного документа.

## Основания трёх эталонов

- [Образовательные программы ФИТ](https://education.nsu.ru/information-technologies/):
  ПИиКН и КНиС представлены как разные профили направления 09.03.01.
- [Абитуриентам ФИТ](https://education.nsu.ru/apply_fit): дистанционное заключение
  договора допускается, по нему указан `fit_prkom@nsu.ru`; есть адрес очного
  оформления. Полный дистанционный регламент не опубликован на этой странице.
- [Первокурсникам НГУ](https://education.nsu.ru/freshmen/): в перечне на заселение
  для военнообязанных указан документ воинского учёта — приписное либо военный
  билет. Контекст сценария ограничен заселением; это не полная инструкция
  постановки на учёт или оформления отсрочки.

URL, разделы, дата проверки и SHA-256 фактически загруженного HTML записаны
в реестре. HTML-снимки вне git, не являются зависимостью тестов. URL и hash
помогают установить редакцию, но не подменяют содержательную проверку.

## Что запросить для остальных вопросов

- **nsu-summer-bachelor-02** — ФИТ: приёмная комиссия: Нужен прямой документ или подтверждение: единая или отдельные конкурсные группы ПИиКН/КНиС в выбранную кампанию. Разные квоты на странице не доказывают порядок конкурса.
- **nsu-summer-bachelor-04** — ФИТ: ответственный за заселение: Нужна начальная последовательность действий и выдачи направления. Нынешние три сценария #388 начинаются с уже оформленных документов и не отвечают, к кому идти сначала. Страница инструкции ФИТ вернула 403 при повторной проверке.
- **nsu-summer-bachelor-05** — ФИТ: учебная часть: Нужен актуальный учебный план/инструкция ФИТ с формами занятий и организацией учебного процесса. Общая страница описывает пары, но не подтверждает весь ответ о лекциях/семинарах; старую аннотацию 2020 года не переносим на нынешний набор.
- **nsu-summer-bachelor-06** — ФИТ: кураторы и учебная часть: Наличие кураторов групп подтверждено, но кто помогает при болезни, кого уведомлять и какие документы требуются, в проверенном источнике не описано.
- **nsu-summer-bachelor-08** — НГУ: кафедра физического воспитания: Нужна текущая инструкция для первого курса: запись/распределение по занятиям, расписание, зачёт, медицинские ограничения. Наличие физкультуры в перечне дисциплин не раскрывает порядок занятий.
- **nsu-summer-master-09** — ФИТ: приёмная комиссия магистратуры: Нужен перечень для выбранной программы, категории и кампании. Центральная страница вернула 403; перечень ПИШ/другого факультета и старые документы не переносим на ФИТ.
- **nsu-summer-master-10** — ФИТ: приёмная комиссия магистратуры: Нужны программа, кампания/год, бюджет или договор и официальный срок соответствующей категории. Не подставлять одну дату для всех вариантов.
- **nsu-summer-master-11** — ФИТ: организатор консультации в магистратуру: Нужны название программы/консультации и кампания, опубликованное расписание и порядок рассылки ссылки. Не обещать срок отправки без источника.
- **nsu-summer-phd-12** — ФИТ: приёмная комиссия аспирантуры: Нужен полный перечень документов и условия выбранной кампании/категории. Обзорная страница подтверждает согласие научного руководителя, но не полный пакет; центральная страница вернула 403.
- **nsu-summer-phd-13** — ФИТ: приёмная комиссия аспирантуры: Нужны назначение/URL конкретной формы, научная специальность и кампания. Форма магистратуры не доказывает ни обязательность, ни отсутствие отдельной формы для аспирантуры.

При повторной проверке центральные страницы магистратуры, аспирантуры и
заселения ФИТ вернули HTTP 403. Это ограничение получения источника,
не свидетельство отсутствия правил и не основание подтвердить старые эталоны.
Вопросы магистратуры/аспирантуры сохранены как реальные обращения: это не
автоматическое расширение согласованного состава R1.

## Запуск и ограничения

```sh
PYTHON_DOTENV_DISABLED=1 uv run python -m evals.validate_summer
PYTHON_DOTENV_DISABLED=1 uv run pytest tests/evals/test_summer_consultation.py
```

Эти команды проверяют полноту разбора, привязки к источникам, отсутствие
неподтверждённых вопросов в исполняемом поднаборе и целостность данных.
Они не измеряют качество живого бота. Не передавать реестр с пробелами судье
как готовые эталоны. Поднабор из трёх ответов не заменяет 50-вопросный набор,
не входит в его показатель 41/45 и не повышает процент за счёт отказов.

Для живого запуска нужны подтверждение эталонов, нужные материалы на
`nsu.abitur.site` и учёт версии данных/настроек. Фактический прогон относится
к #388/#390. В этой работе рабочая БЗ не изменялась, платные запросы к LLM
и новые polling-процессы ботов не запускались.
