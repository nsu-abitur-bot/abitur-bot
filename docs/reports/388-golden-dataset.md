## Источники и пробелы

03.11.2026 прочитаны страницы ФИТ, IT-программ, первокурсников, каталога
бакалавриата, ТИПИ, ММФ, ФФ и ИИР. URL, названия, разделы, дата доступа и
замечания о редакции записаны в реестре. Тексты страниц не объявлены
утверждёнными учебными планами.

Правила приёма, положения о стипендиях, подробная инструкция заселения,
учебный план и паспорт ТИПИ вернули HTTP 403. Страница поступающим НГТУ
не загрузилась из-за таймаута. Эти документы не прочитаны.

Нельзя заменять содержательный ответ перенаправлением только ради успешного теста.

## Выполненные проверки

Все команды запускались с отключённым dotenv. Для тестов указаны фиктивные
адреса PostgreSQL/Redis на `127.0.0.1:1` и тестовые значения конфигурации.
Тесты не используют общие хранилища или ключи моделей.

- `python -m evals.validate_admission` через `uv run --no-sync` - успешно:
  формат v1, 50 уникальных ID и вопросов, квоты, полнота реестра и хеш набора.
- Та же команда с `--require-reviewed` - ожидаемый код 1, подтверждений нет.
- `python -m pytest tests/evals/ -q` через uv - 40 тестов успешно. Включены
  отказы при изменении набора, отсутствующем ревью, неполных записях и
  неподкреплённом экспертном подтверждении.
- Ruff для нового модуля и теста - успешно.
- Pyrefly для нового модуля и теста - 0 ошибок, есть прежнее предупреждение
  о лишних `venvPath` / `venv` в конфигурации.
- Проверка слоёв - успешно, новых нарушений нет.
- Прежний offline-гейт - 8/8 выбранных сценариев, `pass_rate=1.0`, регрессий нет.
  Это результат технического набора, к новым 50 вопросам он не относится.

Первый вызов launcher `uv run pytest` завершился ошибкой
`Failed to canonicalize script path`. Повтор через `uv run python -m pytest`
прошёл. Окружение проекта ради исправления launcher не менялось.
