## Как выполнялась загрузка

Приложение закреплено на `0ec0f788cf590b364e9e7a65f2f0c53de4d5bf40`.
Для извлечения сущностей используется DeepSeek Flash, для эмбеддингов -
GigaChat EmbeddingsGigaR. Все девять страниц текстовые.

Две ранние команды прервались до завершения фиксации результата. Во втором
случае получен код 137. Счётчики памяти старых контейнеров после их удаления
недоступны, поэтому точная причина этих прерываний не подтверждена.

Проверка файлов выявила оборванную матрицу векторов сущностей, отсутствующие
векторы чанков и незаписанную часть графа математики. Сохранены резервные копии.
Векторы восстановлены через GigaChat. Прерванная запись математики обработана
штатной очередью LightRAG с прежним ID и сохранённым кэшем. Для этого продолжения
новых вызовов DeepSeek не потребовалось. После полной сверки восстановлена связь
с PostgreSQL и выполнено принятие через API.

Последние страницы загружал отдельный процесс для каждого источника,
без импорта второго экземпляра FastAPI. Авторизация, создание предложения
и окончательное принятие выполняются через действующий API тестового окружения.
Индексация использует тот же `GraphMemory`, что и приложение. Перед принятием
проверяются файлы графа, исходный текст и готовая запись PostgreSQL.
Это техническое принятие источников для тестов. Проверка эталонных ответов
ведётся отдельно.

Для новой партии сохранены лимиты 512 генераций, 8192 запросов эмбеддингов,
16 OAuth-запросов и плановый предел DeepSeek 20 CNY по пиковым ставкам без кэша.
Из него 10 CNY зарезервированы на неопределённость двух прерываний.
Счётчики переносятся между процессами. Неизвестный адрес, редирект, ошибка
или неполный usage останавливают следующие обращения к провайдерам.
Векторные файлы записываются через временный файл с `fsync` и атомарной заменой.

В одной попытке резервного копирования не был учтён отсутствующий файл кэша.
Она остановилась до обращений к моделям. Ошибка исправлена, её отчёты сохранены,
а уже созданное предложение использовано при продолжении.
