# Система категоризации вопросов

## Обзор

Система автоматически классифицирует вопросы пользователей по категориям при обработке сообщений. Это позволяет анализировать типы вопросов абитуриентов и улучшать работу бота.

## Категории

### Основные категории

- **admission** - Поступление, правила, сроки
- **programs** - Образовательные программы, специальности  
- **exams** - Экзамены, ЕГЭ, вступительные испытания
- **scores** - Проходные баллы, конкурсы
- **dorms** - Общежития
- **documents** - Документы, подача заявлений
- **cost** - Стоимость обучения, льготы
- **campus** - Кампус, инфраструктура
- **student_life** - Студенческая жизнь
- **career** - Карьера после выпуска
- **transfer** - Перевод, восстановление
- **military** - Военная кафедра
- **international** - Иностранным абитуриентам
- **general** - Общие вопросы об НГУ
- **offtop** - Не относящиеся к НГУ

## Архитектура

### Компоненты

1. **config/question_categories.py** - Конфигурация категорий и описаний
2. **db/postgres/models.py** - Модель Message с полями category и tagged_at
3. **db/postgres/services/message_category.py** - Сервис для работы с категориями
4. **llm/llm_client.py** - Интеграция классификации в обработку сообщений
5. **bot/category_handlers.py** - Админские команды для управления

### Процесс классификации

1. Пользователь отправляет сообщение
2. LLM классифицирует сообщение в одну из категорий
3. Категория и дата тегирования сохраняются в БД
4. Сообщение обрабатывается дальше (FAQ, RAG, LLM ответ)

## Админские команды

Доступны только администраторам (ID указываются в `ADMIN_IDS`):

- `/category_stats` - Статистика по категориям
- `/category_info` - Информация о категориях
- `/tag_messages` - Тегировать сообщения без категории
- `/retag_week` - Перетегировать сообщения за неделю

## Массовое тегирование

### Утилита tag_messages.py

```bash
python utils/tag_messages.py
```

Функции:
- Тегирование существующих сообщений
- Перетегирование по датам
- Статистика тегирования

### API методы

```python
from db.postgres.services.message_category import MessageCategoryService

# Создать сервис
async with AsyncSessionLocal() as db_session:
    service = MessageCategoryService(db_session)
    
    # Классифицировать сообщение
    category = await service.classify_message("Какие баллы нужны на ИТ?")
    
    # Обновить категорию сообщения
    await service.update_message_category(message_id, category)
    
    # Получить статистику
    stats = await service.get_category_statistics()
```

## Конфигурация

### Администраторы

В `.env`:
```env
ADMIN_IDS=123456789,987654321
```

### Настройка категорий

В `config/question_categories.py`:
- Добавить новые категории в enum `QuestionCategory`
- Обновить описания в `CATEGORY_DESCRIPTIONS`
- Перегенерировать промпт при необходимости

## Аналитика

Статистика включает:
- Общее количество сообщений
- Количество сообщений по категориям
- Процент тегированных сообщений
- Динамику по времени

## Важные моменты

1. **Дата тегирования** - нужна для отслеживания изменений в системе категоризации
2. **Принудительное обновление** - позволяет перетегировать сообщения при обновлении категорий
3. **Обработка ошибок** - при ошибке классификации используется категория "general"
4. **Производительность** - классификация происходит асинхронно и не блокирует ответ пользователю
