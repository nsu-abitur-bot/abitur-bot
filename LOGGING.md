# Настройка логирования в проекте

## Обзор

В проекте настроено централизованное логирование с записью в несколько файлов и ротацией логов.

## Файлы логов

Все логи сохраняются в директории `logs/` (создаётся автоматически):

### 1. `logs/abitur_bot.log`
- **Назначение**: Основной файл логов всего приложения
- **Уровень**: DEBUG и выше
- **Размер**: до 10MB
- **Резервные копии**: 5 файлов

### 2. `logs/rag_llm_detailed.log`
- **Назначение**: Подробные логи RAG и LLM операций
- **Уровень**: DEBUG и выше
- **Размер**: до 50MB
- **Резервные копии**: 10 файлов
- **Содержит**: 
  - Что достали из RAG (контекст и источники)
  - Что ответил LLM (сырой ответ и финальный)
  - FAQ совпадения

### 3. `logs/errors.log`
- **Назначение**: Только ошибки
- **Уровень**: ERROR и выше
- **Размер**: до 5MB
- **Резервные копии**: 3 файла

## Что логируется

### Сообщения от пользователей
```
[123456789] Сообщение от UserName в чате 123456789: Как поступить в НГУ?
[123456789] Sending message to LLM: [from UserName] Как поступить в НГУ?
```

### FAQ совпадения
```
[123456789] Checking FAQ for match.
[123456789] FAQ result:
[123456789] - Matched FAQ answer: Для поступления в НГУ нужно...
```

### RAG ретривал
```
[123456789] Querying LightRAG for context.
[123456789] RAG retrieval result:
[123456789] - Context (first 500 chars): НГУ (Новосибирский государственный университет)...
[123456789] - Sources (3): ['https://nsu.ru/admission', 'https://nsu.ru/rules', ...]
```

### LLM ответы
```
[123456789] LLM response result:
[123456789] - Raw response (first 500 chars): Для поступления в Новосибирский государственный университет...
[123456789] - Response length: 1247 characters
[123456789] Final bot response to user: Для поступления в НГУ необходимо подать документы...
```

## Настройка

### Переменные окружения

В `.env` файле можно настроить:

```bash
# Уровень логирования: DEBUG | INFO | WARNING | ERROR | CRITICAL
LOG_LEVEL=INFO

# Директория для логов (по умолчанию: logs)
LOG_DIR=logs
```

### Уровни логирования

- **DEBUG**: Максимальная детализация (все RAG и LLM операции)
- **INFO**: Базовая информация (рекомендуется для продакшена)
- **WARNING**: Предупреждения и ошибки
- **ERROR**: Только ошибки

## Просмотр логов

### Все сообщения пользователя
```bash
tail -f logs/rag_llm_detailed.log | grep "123456789"
```

### Только RAG операции
```bash
tail -f logs/rag_llm_detailed.log | grep "RAG retrieval result"
```

### Только LLM ответы
```bash
tail -f logs/rag_llm_detailed.log | grep "LLM response result"
```

### Ошибки
```bash
tail -f logs/errors.log
```

## Ротация логов

Логи автоматически ротируются при достижении максимального размера:
- Старые файлы переименовываются в `filename.log.1`, `filename.log.2` и т.д.
- Самые старые файлы удаляются
- Это позволяет контролировать дисковое пространство

## Структура логгеров

- `bot.main` - Основные операции бота
- `llm.llm_client` - LLM запросы и ответы
- `rag.graph_memory` - RAG операции
- Внешние библиотеки (`aiogram`, `asyncpg`, `lightrag`) - уровень WARNING для уменьшения шума
